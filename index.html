📦 Μάθημα 1 — Κουτιά που κρατάνε πράγματα (Μεταβλητές)

Φαντάσου ένα ράφι με κουτιά. Κάθε κουτί έχει ένα όνομα πάνω του, και μέσα βάζεις ένα πράγμα. Στην C++ αυτά τα κουτιά τα λέμε μεταβλητές.

Οι 4 τύποι κουτιών

ΤύποςΤι κρατάειΠαραδείγματα
intΑκέραιους αριθμούς (χωρίς δεκαδικά)5, 42, -7, 0
floatΑριθμούς με δεκαδικά1.75, 3.14, -0.5
charΈναν μόνο χαρακτήρα'A', 'x', '7'
boolΑληθές ή ψευδέςtrue, false

Πώς φτιάχνω ένα κουτί;

Πάντα με την ίδια σειρά: τύπος → όνομα → = → τιμή → ;

τύπος   όνομα   =   τιμή   ;
#include <iostream>
using namespace std;

int main(){
    int   ilikia      = 9;        // ακέραιος αριθμός
    float ypsos       = 1.35;     // δεκαδικός αριθμός
    char  gramma      = 'A';      // ΕΝΑΣ χαρακτήρας
    bool  einaiPaidi  = true;     // αληθές / ψευδές

    cout << ilikia << endl;
    return 0;
}
📌 Οδηγίες — Πρόσεχε αυτά:
  • Κάθε εντολή τελειώνει με ; — όπως βάζουμε τελεία στην πρόταση.
  • Τα ονόματα γράφονται με λατινικά γράμματα, χωρίς κενά και χωρίς τόνους. (ilikia ✅   ηλικία ❌)
  • Οι δεκαδικοί γράφονται με τελεία: 1.35 ✅   1,35 ❌
  • Ο char θέλει μονά εισαγωγικά: 'A' ✅   "A" ❌
  • Ο bool παίρνει μόνο true ή false — με μικρά γράμματα!

🗣️ Μάθημα 2 — Μιλάω με τον υπολογιστή (cout & cin)

Ο υπολογιστής είναι σαν ένα κουτί που δεν μιλάει. Για να συνεννοηθούμε έχουμε δύο πόρτες: μία για να βγάζουμε πράγματα και μία για να βάζουμε.

🔼 cout — «βγάζω έξω» (τυπώνω στην οθόνη)

Σκέψου: c-out = βγάζω έξω. Τα βελάκια << δείχνουν προς το cout, γιατί του δίνουμε πράγματα.

cout << "Γεια σου!" << endl;
  • "Γεια σου!" → κείμενο μέσα σε διπλά εισαγωγικά
  • endl → σημαίνει end line = αλλαγή γραμμής

🔽 cin — «βάζω μέσα» (διαβάζω από το πληκτρολόγιο)

Σκέψου: c-in = βάζω μέσα. Τα βελάκια >> δείχνουν προς τη μεταβλητή, γιατί εκείνη δέχεται την τιμή.

int x;
cin >> x;

Ένα ολόκληρο πρόγραμμα

#include <iostream>      // φέρνει το cout και το cin
using namespace std;

int main(){
    int ilikia;                                    // 1. φτιάχνω το κουτί

    cout << "Πόσο χρονών είσαι; ";                // 2. ρωτάω
    cin  >> ilikia;                                // 3. διαβάζω την απάντηση

    cout << "Είσαι " << ilikia << " χρονών!" << endl;
    return 0;
}
📌 Οδηγίες — Η «συνταγή» κάθε προγράμματος:
  • #include <iostream> — πάντα πρώτο, φέρνει τα εργαλεία εισόδου/εξόδου.
  • using namespace std; — για να γράφουμε cout και όχι std::cout.
  • int main(){ ... } — εδώ μέσα γράφουμε τις εντολές μας.
  • return 0; — «τελείωσα, όλα καλά».
  • Μπορώ να τυπώσω πολλά μαζί: cout << "Ηλικία: " << ilikia << endl;
⚠️ Προσοχή: Το κείμενο θέλει διπλά εισαγωγικά "...", ενώ οι μεταβλητές δεν θέλουν καθόλου εισαγωγικά. Το cout << "ilikia" τυπώνει τη λέξη ilikia, ενώ το cout << ilikia τυπώνει την τιμή της!

➗ Μάθημα 3 — Πράξεις (η αριθμομηχανή μας)

Η C++ είναι μια πολύ γρήγορη αριθμομηχανή. Τα σύμβολα που χρειαζόμαστε είναι μόνο πέντε!

ΣύμβολοΤι κάνειΠαράδειγμαΑποτέλεσμα
+Πρόσθεση5 + 38
-Αφαίρεση5 - 32
*Πολλαπλασιασμός5 * 315
/Διαίρεση6 / 32
%Το υπόλοιπο της διαίρεσης7 % 31

🔎 Το % με ένα παραμύθι

Έχεις 17 καραμέλες και 5 φίλους. Μοιράζεις δίκαια:

  • 17 / 5 → 3 καραμέλες στον καθένα
  • 17 % 5 → 2 καραμέλες περισσεύουν
⚠️ Η μεγάλη παγίδα — διαίρεση με ακεραίους!

Αν και οι δύο αριθμοί είναι int, η C++ πετάει τα δεκαδικά:

cout << 7 / 2 << endl;      // τυπώνει 3  (όχι 3.5!)
cout << 7.0 / 2 << endl;    // τυπώνει 3.5 (ο 7.0 είναι float)
📌 Οδηγίες:
  • Ο πολλαπλασιασμός γράφεται * — όχι x και όχι ·.
  • Το % (modulo) σημαίνει «τι περισσεύει». Χρήσιμο για να βρεις αν ένας αριθμός είναι άρτιος: n % 2 == 0.
  • Μπορώ να αποθηκεύσω το αποτέλεσμα: int apotelesma = a + b;
  • Η σειρά μετράει, όπως στα μαθηματικά: πρώτα * και /, μετά + και -. Οι παρενθέσεις () αλλάζουν τη σειρά.
#include <iostream>
using namespace std;

int main(){
    int a = 10, b = 3;
    cout << "Άθροισμα: "     << a + b << endl;   // 13
    cout << "Διαφορά: "      << a - b << endl;   // 7
    cout << "Γινόμενο: "     << a * b << endl;   // 30
    cout << "Πηλίκο: "       << a / b << endl;   // 3
    cout << "Υπόλοιπο: "     << a % b << endl;   // 1
    return 0;
}

🧰 Μάθημα 4 — cmath: η εργαλειοθήκη των μαθηματικών

Η C++ έχει ένα κουτί γεμάτο μαθηματικά εργαλεία. Για να το ανοίξουμε γράφουμε #include <cmath> στην αρχή του προγράμματος.

ΕργαλείοΤι κάνειΠαράδειγμαΑποτέλεσμα
pow(a, b)Δύναμη: a υψωμένο στη bpow(2, 5)32
sqrt(x)Τετραγωνική ρίζαsqrt(81)9
trunc(x)Πετάει τα δεκαδικά (κόβει)trunc(3.9)3
round(x)Στρογγυλοποιεί στον κοντινότεροround(3.7)4
abs(x)Απόλυτη τιμή (χωρίς το μείον)abs(-7)7
📌 Οδηγίες:
  • Πάντα #include <cmath> στην αρχή — αλλιώς το πρόγραμμα δεν ξέρει τι είναι το pow.
  • Τα ονόματα γράφονται με μικρά γράμματα: pow ✅   Pow ή POW ❌
  • Μετά το όνομα του εργαλείου ανοίγουμε παρένθεση και βάζουμε την τιμή: sqrt(25).
  • Το αποτέλεσμα μπορεί να αποθηκευτεί σε μεταβλητή: float r = sqrt(25);
#include <iostream>
#include <cmath>          // εδώ είναι τα pow, sqrt, round...
using namespace std;

int main(){
    cout << pow(3, 2)    << endl;   // 9
    cout << sqrt(64)     << endl;   // 8
    cout << round(4.6)   << endl;   // 5
    cout << trunc(4.9)   << endl;   // 4
    cout << abs(-12)     << endl;   // 12
    return 0;
}
💡 Διαφορά trunc και round: Το trunc(4.9) δίνει 4 (απλά κόβει το ,9). Το round(4.9) δίνει 5 (κοιτάει ποιος είναι πιο κοντά).

🎀 Μάθημα 5 — iomanip: ομορφαίνω τους αριθμούς

Φαντάσου ότι θέλεις να δείξεις 3.14159 αλλά μόνο με 2 δεκαδικά: 3.14. Γι' αυτό υπάρχει το <iomanip>.

Τα δύο εργαλεία

  • fixed → «θέλω σταθερό αριθμό δεκαδικών ψηφίων»
  • setprecision(n) → «θέλω n δεκαδικά ψηφία»

Τα γράφουμε μαζί, μέσα στο cout:

cout << fixed << setprecision(2) << 3.14159 << endl;   // 3.14
📌 Οδηγίες:
  • #include <iomanip> στην αρχή του προγράμματος.
  • Το fixed μπαίνει πριν το setprecision — πάντα με αυτή τη σειρά.
  • Ό,τι τυπώσεις μετά από αυτό θα έχει τόσα δεκαδικά, μέχρι να το αλλάξεις ξανά.
  • Αν ξεχάσεις το fixed, το setprecision(2) σημαίνει «2 συνολικά ψηφία» και θα σου τυπώσει 3.1 — προσοχή!
#include <iostream>
#include <iomanip>       // εδώ είναι το fixed και το setprecision
using namespace std;

int main(){
    float pi = 3.14159;

    cout << fixed << setprecision(2) << pi << endl;   // 3.14
    cout << fixed << setprecision(4) << pi << endl;   // 3.1416

    float mish = 2.5;
    cout << fixed << setprecision(3) << mish << endl; // 2.500
    return 0;
}
💡 Τέλειο ζευγάρι: Το sqrt(2) δίνει 1.41421356.... Με cout << fixed << setprecision(2) << sqrt(2); τυπώνεις καθαρά 1.41.

🤔 Μάθημα 6 — if / else: παίρνω αποφάσεις

Ο υπολογιστής μπορεί να σκέφτεται σαν εμάς: «ΑΝ κάνει κρύο, φόρα ζακέτα, ΑΛΛΙΩΣ φόρα μπλουζάκι».

if (συνθήκη) {
    // γίνεται αυτό αν η συνθήκη είναι ΑΛΗΘΙΝΗ
} else {
    // γίνεται αυτό αν είναι ΨΕΥΔΗΣ
}

Οι «λέξεις» που ρωτάνε

ΣύμβολοΣημαίνειΠαράδειγμα
>μεγαλύτεροx > 0
<μικρότεροx < 10
>=μεγαλύτερο ή ίσοvathmos >= 5
<=μικρότερο ή ίσοx <= 100
==είναι ίσο μεx == 5
!=δεν είναι ίσο μεx != 5
⚠️ Η ΠΙΟ ΣΗΜΑΝΤΙΚΗ ΠΑΓΙΔΑ ΟΛΩΝ:
  • == (δύο ίσον) ρωτάει: «είναι ίσο;» → μέσα σε if
  • = (ένα ίσον) δίνει τιμή → μέσα σε δήλωση μεταβλητής

Το if (x = 5) είναι λάθος! Το σωστό είναι if (x == 5).

📌 Οδηγίες:
  • Η συνθήκη μπαίνει πάντα μέσα σε παρενθέσεις ( ... ).
  • Οι εντολές μέσα στα { } — προσοχή στις αγκύλες!
  • Το else δεν έχει παρένθεση και δεν έχει ; μετά.
  • Μπορώ να έχω μόνο if, χωρίς else, αν δεν θέλω να κάνω κάτι στην περίπτωση που είναι ψευδές.
#include <iostream>
using namespace std;

int main(){
    int vathmos;
    cout << "Δώσε βαθμό: ";
    cin >> vathmos;

    if (vathmos >= 5) {
        cout << "Πέρασες! 🎉" << endl;
    } else {
        cout << "Κόπηκες... 💪" << endl;
    }
    return 0;
}
