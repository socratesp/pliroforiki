Binary ⇄ Decimal

Binary is a base‑2 system: it uses only the digits 0 and 1. Decimal is base 10, using 0–9.

Binary → Decimal

Each binary digit (a bit) has a place value — a power of 2 — determined by its position. Positions are counted from the right, starting at 2⁰ = 1.

Position7654 3210
Place value 128643216 8421

To convert: multiply every bit by its place value, then add all the results together. Bits equal to 0 contribute nothing.

Example — 1011 in binary
1 × 2³ = 8
0 × 2² = 0
1 × 2¹ = 2
1 × 2⁰ = 1
────────────────
8 + 0 + 2 + 1 = 11
Shortcut — “double and add” (Horner's method): read the bits left to right. Start with value = 0, then for each bit do: value = value × 2 + bit Why it works Each × 2 shifts every existing bit one place to the left in the place-value table (8s become 16s, 4s become 8s, and so on). Adding the new bit then fills the empty units (2⁰) position. So you build the number one place at a time — no need to pre-compute powers of 2. Step-by-step for 1011 Bits are read in this order: 1, 0, 1, 1

0 → 1 → 2 → 5 → 11 What happens at each step
  • Step 1 — start at 0, read the first bit 1. → 0 × 2 + 1 = 1
  • Step 2 — read 0. The 1 shifts left (becomes 2), and 0 goes into the units. → 1 × 2 + 0 = 2
  • Step 3 — read 1. The 2 shifts left (becomes 4), and 1 goes into the units. → 2 × 2 + 1 = 5
  • Step 4 — read 1. The 5 shifts left (becomes 10), and 1 goes into the units. → 5 × 2 + 1 = 11

  • Place-value (right to left): 1×8 + 0×4 + 1×2 + 1×1 = 11
  • Double-and-add (left to right): ((((0×2+1)×2+0)×2+1)×2+1) = 11
Both give 11. The double-and-add method is often faster to do mentally because you never need to count positions or remember powers of 2 — you just keep doubling and adding.

Decimal → Binary

Use repeated division by 2. Divide the number by 2, write down the remainder, then divide the quotient again — until the quotient reaches 0. Finally, read the remainders from the bottom up.

Example — convert 45 to binary
45 ÷ 2 = 22   remainder 1
22 ÷ 2 = 11   remainder 0
11 ÷ 2 =  5   remainder 1
 5 ÷ 2 =  2   remainder 1
 2 ÷ 2 =  1   remainder 0
 1 ÷ 2 =  0   remainder 1
────────────────────────────
Read bottom → top: 101101

Every remainder is either 0 or 1, which is exactly why the result contains only those two digits. The last remainder you write is always the leading (leftmost) bit of the answer.

Hexadecimal ⇄ Decimal

Hexadecimal is a base‑16 system. It uses 0–9 for values 0–9 and the letters A–F for 10–15.

The sixteen hex digits

Because a single symbol is needed for every value from 0 to 15, hex borrows letters for the values above 9:

HexABCDEF
Decimal 101112131415

Hex → Decimal

The method is identical to binary, except the place values are powers of 16 instead of powers of 2 — again counted from the right, starting at 16⁰ = 1.

Position43210
Place value 655364096256161

Multiply each hex digit by its place value (converting letters to 10–15 first), then add.

Example — 2F in hex
2 × 16¹ = 2 × 16 = 32
F × 16⁰ = 15 × 1 = 15
──────────────────
32 + 15 = 47
Example — 1A3 in hex
1 × 16² = 1 × 256 = 256
A × 16¹ = 10 × 16 = 160
3 × 16⁰ = 3 × 1 = 3
────────────────────────
256 + 160 + 3 = 419

Decimal → Hex

Same idea as decimal → binary, but divide by 16 instead of 2. Each remainder is a value between 0 and 15 — turn anything above 9 into its letter (10 → A, 11 → B, … 15 → F). Then read the remainders from the bottom up.

Example — convert 419 to hex
419 ÷ 16 = 26   remainder  3
 26 ÷ 16 =  1   remainder 10 → A
  1 ÷ 16 =  0   remainder  1
──────────────────────────────
Read bottom → top: 1A3
Hex ↔ binary link: one hex digit is exactly four bits. So 1A3 becomes 0001 1010 0011, and 1011 becomes B. This makes hex a compact shorthand for binary.
